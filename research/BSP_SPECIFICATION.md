# BSP Specification

## Status
**RESEARCH / PENDING VERIFICATION**

BSP means **Bhrigu Saral Paddhati** in this project.

Every production BSP rule must have a source-traceable record: Rule ID, exact statement, planet, natal condition, house/sign condition, running-year condition, transit/aspect conditions, modifiers, exceptions, interpretation, author, source location, confidence and test case.

Generic Jyotish rules must not silently become BSP rules.
